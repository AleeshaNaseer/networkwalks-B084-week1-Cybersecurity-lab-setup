# networkwalks-B084-week1-Cybersecurity-lab-setup
First Cybersecurity Lab Setup
Project: Virtual Cybersecurity & Penetration Testing Lab Setup

I successfully set up a virtual cybersecurity and penetration-testing lab using **Oracle VirtualBox and Kali Linux**.

The project focuses on creating a controlled and isolated virtual environment for learning cybersecurity concepts and practicing authorized security testing.

Key Tasks Completed:
- Installed and configured Oracle VirtualBox.
- Installed and configured Kali Linux as a virtual machine.
- Created a private NAT Network for the lab environment.
- Configured network connectivity and IP addressing.
- Verified internet connectivity and DNS resolution.
- Created a clean VM snapshot for recovery.
- Documented the complete setup process.

Lab Applications:
- Network Reconnaissance
- Port Scanning
- Vulnerability Assessment
- Packet Analysis
- Web Security Testing
- Penetration Testing Practice
- Cybersecurity Tool Exploration
